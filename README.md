# Hexcraft Workshop · 海克斯工坊

一款以 **Minecraft 1.20.1（Forge）** 为主的玩法强化模组。
灵感来自《英雄联盟》海克斯大乱斗（ARAM Mayhem）与斗魂竞技场（Arena）：
以 **「双资源 → 三选一构筑」** 为核心——抽取海克斯增幅、购买属性锻造器、穿戴词条装备，构筑属于你的流派。

- **作者**：GuJiaoYe、豆包

- **支持版本**：Minecraft 1.20.1（Forge 47.x）

## 快速开始

### 环境要求

- Minecraft **1.20.1** + Forge **47.4.23 及以上**（1.20.1 系）
- Java 17（Forge 要求）
- 可选依赖：**[Cloth Config API](https://modrinth.com/mod/cloth-config)**（v10+）——未安装时 MOD 正常运行，仅配置界面不显示（配置仍可在 `config/` 下 TOML 手动修改）
- 可选联动：**TACZ（永恒枪械工坊）** ——自动检测，未安装不影响

### 安装

1. 安装 Forge 1.20.1（47.x）
2. 将 `hexworkshop-1.20.1-<版本>.jar` 放入 `.minecraft/mods/`
3. （可选）安装 Cloth Config API 以使用游戏内配置界面
4. 启动游戏，背包界面右上角点击「◆」或按 **H** 键打开海克斯工坊

> 客户端与服务端都放入即可；仅服务端有该 MOD 时，联机玩家无需安装（数据由服务端权威，客户端界面依赖 MOD 本体，推荐双方都装）。

### 指令（OP）

```
/hexcraft coins add <玩家> <数量>      # 添加晶币
/hexcraft coins set <玩家> <数量>      # 设置晶币
/hexcraft view <玩家>                  # 查看玩家数据
/hexcraft clear <玩家>                 # 清空玩家数据
/hexcraft reload [all|hexes|forging|equipment|world]   # 分模块重载数据包定义（热更新，客户端界面自动刷新）
```

## 数据驱动与联动扩展

海克斯 / 装备 / 世界海克斯全部由 **数据包 JSON 驱动**（`data/hexworkshop/hextech/*.json`、`equipment/*.json`、`world_hexes/*.json`，v0.6.0 起锻造词条池也可经数据包覆写），
无需改代码即可增删改内容；事件效果由 `event` 字段效果 key 驱动（吸血 / 暴击 / 复合机制 / 成长层数 / 矿物 / 枪械 / 叠层等）。

联动 mod 接入：注册一个 id 前缀即自动检测 + 默认启用 + 可配置关闭。

**详细文档**：
- [开发者指南（如何新增海克斯 / 装备 / 锻造词条 / 联动 MOD）](docs/DEVELOPER.md)
- [发布介绍文案与检查清单](docs/PUBLISHING.md)
