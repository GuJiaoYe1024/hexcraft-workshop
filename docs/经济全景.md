# 经济全景：晶币与经验的收支

对应规范：14-经济与资源循环。本文的数值全部来自 `HexConfig` 实际默认值（2026-11-14 核对），不是设计意图。

---

## 1. 两条货币，性质完全不同

| 货币 | 性质 | 谁来管 |
|---|---|---|
| **晶币** | 本 mod 自建的封闭货币，只能靠击杀/任务/补偿获得，只能在本 mod 里花 | `HexConfig` 全部可调 |
| **经验** | 原版资源，本 mod 只是**消耗**它，不生产它 | 抽卡消耗量可调，产出速率由整合包决定 |

这个区别很关键：经验不是本 mod 的 faucet，玩家练级快慢取决于整合包。所以「经验够不够用」这个问题的答案，本 mod 只能通过调低消耗来解决，不能通过加产出。

---

## 2. Faucet（晶币从无到有）

### 2.1 击杀掉落（主水源）

| 目标 | 默认范围 | 均值 |
|---|---|---|
| 普通怪 | 1 ~ 3 | 2 |
| 精英怪（生命 ≥ 40） | 5 ~ 10 | 7.5 |
| 首领怪（生命 ≥ 120） | 20 ~ 50 | 35 |

配置键：`coinMin` / `coinMax` / `coinEliteMin` / `coinEliteMax` / `coinBossMin` / `coinBossMax`。

**反刷机制**：`antiFarmWindowSec` 30 秒内重复击杀同种怪，掉落衰减到 `antiFarmDecay` = 20%。这是第一道通胀阀门，默认开启。

### 2.2 其它 faucet

| 来源 | 数值 | 备注 |
|---|---|---|
| 满级重复补偿 | 白银 10 / 黄金 30 / 棱彩 80 | `refundSilver` / `refundGold` / `refundPrismatic`。抽到已满级的海克斯返还晶币——**这是 faucet，不是 sink**，容易看反 |
| `coin_bonus` 事件键 | 按海克斯等级 | 部分海克斯直接加晶币 |
| `bounty` 事件键 | 按配置 | 悬赏类 |
| `loot_double` 事件键 | 战利品翻倍 | **隐藏 faucet**：翻倍的是掉落物，间接抬高晶币与材料供给 |
| FTB 任务奖励 | 按任务 | `quest` 系列事件键 |
| EMC 充值 | 1 钻石 = 8 晶币（汇率 1024） | 把 ProjectE 的 EMC 换成晶币，等于给整合包开了一条外部注水口 |

### 2.3 随机馈赠

`loot_double` 与脚边掉落类事件会在击杀时额外给物品。这类 faucet 不写在配置里，只能从事件键反查。

## 3. Sink（晶币被永久销毁）

### 3.1 锻造器（主水池）

| 类型 | 默认价格 | 说明 |
|---|---|---|
| 基础 | 100 | `forgeBasicPrice`（v0.9.9 由 50 调到 100，按 EMC 价值对齐） |
| 黄金 | 200 | `forgeGoldPrice`（原 150） |
| 棱彩 | 450 | `forgePrismaticPrice`（原 400） |
| 随机 | 175 | `forgeRandomPrice` |

锻造次数默认**无上限**（`forgeLimit` = 0），意味着这是一个可以无限重复使用的 sink——符合规范里「sink 要被反复使用」的要求。

### 3.2 抽卡与刷新

| 项 | 消耗 |
|---|---|
| 海克斯抽取 | 400 经验起，每抽一次下次 +10%（`xpCostPerDraw` + `xpIncrementRate`） |
| 三选一刷新 | 20 晶币（`rerollCost`） |
| 手动抽敌方海克斯 | 300 经验 + 50 晶币 |
| 手动抽敌方锻造器 | 200 经验 + 80 晶币 |

### 3.3 装备

装备有 `sell` 字段（出售价），是**反向** faucet——卖装备换晶币。所以装备既是消耗（买）也是来源（卖），净流向取决于买卖价差。

## 4. 收支比怎么算

规范要求按三档玩家分别算。这里给可填的算法，不编造数字。

**晶币**

```
一次会话收入 = (普通怪击杀数 × 2 + 精英击杀数 × 7.5 + 首领击杀数 × 35) × 反刷修正
            + 满级重复补偿次数 × 对应档位
            + 任务 / 事件键额外产出
一次会话支出 = 锻造次数 × 平均单价 + 刷新次数 × 20 + 敌方抽取次数 × 130
收支比 = 收入 / 支出
```

**经验**

```
收入 = 整合包决定（本 mod 不生产）
支出 = 抽取次数 × 400 × (1 + 0.10 × 已抽次数)
```

三档玩家的差别主要在「击杀数」和「锻造次数」这两个乘数上：

| 玩家档 | 典型特征 | 要观察什么 |
|---|---|---|
| 休闲 | 单次会话 30~60 分钟，击杀少 | 会不会**攒不起**一次锻造（sink 过紧） |
| 平均 | 单次 1~2 小时，稳定进展 | 收支比是否接近 1 |
| 重度 | 长时间刷怪 + 反刷机制失效时段 | 晶币是否**堆积到没处花**（faucet 过松） |

## 5. 现有阀门与缺口

**已有的阀门**

- 反刷衰减（30 秒窗口降到 20%）
- 经验递增（每抽 +10%）
- 锻造价格按 EMC 对齐（防止晶币相对 EMC 贬值）
- 棱彩价格 450 与白银 100 形成 4.5 倍梯度，和稀有度权重 40/35/25 配合

**明确缺口**

| 缺口 | 说明 |
|---|---|
| **没有实测收支比** | 本 mod 没有任何会话级统计。`/hexworkshop pickstats` 记的是选取率，不是晶币进出。要知道真实比值只能靠玩家实测或加埋点 |
| **晶币无上限** | 玩家可以无限囤积，没有「必须花掉」的压力。规范提醒过：不要指望玩家自愿花掉，sink 必须是想做的事——锻造是「想做的事」，所以这条还好 |
| **EMC 充值是对外接口** | 整合包 EMC 产量高的话，晶币会被外部注水。这不是本 mod 能控的，但要知道这条口子存在 |

## 6. 判断 sink 是否有效（对照规范三条）

| 标准 | 本项目 | 结论 |
|---|---|---|
| 被反复使用 | 锻造无次数上限，抽卡无限 | ✅ |
| 被玩家理解 | 价格写在界面按钮上 | ✅ |
| 对齐玩家想做的事 | 锻造器是「变强」，不是维护费 | ✅ |
| 不像交税 | 没有耐久税、没有周期性收费 | ✅ |

四条都过。这也是为什么本项目不需要加「维护费」类 sink——规范明确说那种东西会引发抵触。

## 7. 未测量项（如实标注）

以下都是**没有数据**的，不要当成已知：

- 三档玩家的实际收支比
- 反刷机制在实际游玩中的触发率
- `loot_double` 带来的隐性晶币增量
- EMC 充值的实际使用频率

要拿到这些数，最小改动是在 `PlayerData` 里加两个计数器（累计获得 / 累计消耗），由 `/hexworkshop ecostats` 输出。这属于新功能，未实施。
