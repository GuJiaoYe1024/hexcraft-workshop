# v1.0.0 界面重置前瞻蓝图（界面 + 交互 + 显示全量重做）

> 状态：前瞻调研完成 · 蓝图定稿 · 实施待 v1.0.0 版本启动
> 口径：玩家自选 3~10 个池抽海克斯 / 单一总池 / 三大分类池 三种模式并存；
> 界面做大、做「网游感」，不再是扁长方形；交互与显示全部重做。

---

## 1. 调研结论（勿闭门造车——官方做法盘点）

### 1.1 英雄联盟手游 / 符文大乱斗（海克斯强化正主）

| 官方做法 | 出处 | 对我们的启示 |
|---|---|---|
| **升级增幅装置选择画面**：「增幅裝置選擇畫面……看起來比以往更加令人驚豔」——官方专门把选择界面做成了大画面、全屏卡牌 | Wild Rift 官方 2025-05 更新说明 | 抽卡主界面 = 全屏大卡牌，不是扁长条；玩家这条「和网游一样、做大」诉求与官方方向一致 |
| **增幅装置资料库**：模式入口右上角按钮打开，查看每个增幅装置**摘要 + 详细描述 + 升级后强化效果** | 同上 | 图鉴页签升级：列表摘要 + 点击进详情覆盖层（描述/机制/档位/连锁） |
| **增幅装置强化（收集连锁）**：收集同系列增幅装置 → 获得额外加成/升级效果（精準神射手基本→强化） | 同上 | 我们的羁绊档位 + 满员棱彩 ×2 就是同构设计，界面要把它显性化成「连锁进度」 |
| **命运/未知增幅装置连锁**：收集 3 件升等级上限、收集 4 件抽额外装置/升级星光 | 同上 | 羁绊页签可做「集齐 N 件 → 解锁/升级」的成就化展示 |
| **随机性优化**：被跳过的增幅装置不会在未来选择画面再次出现 | 同上 | 抽卡池去重：本次会话跳过的海克斯后续抽取剔除，减少重复感 |
| **海克斯图鉴入口**（双人竞技场 5.3 版本）：模式入口新增图鉴按钮，查看全部强化符文卡 | 游侠手游（2024-10 报道） | 入口前置：主界面直达「全量图鉴」，不必先开一局 |
| **增幅装置档案 Augment Archive**（Patch 7.0）：所有强化详情游戏内可查 | Wild Rift Patch 7.0（2026-01） | 全量图鉴 + 详情检索是官方标配 |

### 1.2 云顶之弈 TFT（强化符文 = 我们这套体系的原型）

| 官方做法 | 出处 | 对我们的启示 |
|---|---|---|
| **一局三次、每次三选一、选一弃二**；可**金币重投（reroll）** | TFT 官方（Gizmos & Gadgets 机制概述） | 抽取流程：三选一 + 重投（我们已有三选一；重投可做成消耗晶币换池/换选项） |
| **三种稀有度等级**：白银/黄金/棱镜（Prismatic），选择画面每张卡按稀有度着色 + 推荐药丸带稀有度描边发光 | TFT Patch 18.5（tftsense）/ 官方补丁 | 卡牌稀有度色 + 光效已有雏形（我们 v0.9.7 已做稀有度闪光扫线），v1.0.0 升级为整卡氛围光 |
| **英雄传说之力 Legends**：开局 15 选 1，影响后续强化符文池（最左选项必定关联） | TFT Runeterra Reforged 机制概述 | **池子选择已有官方先例**：开局选池 → 影响抽取池；玩家「自选 3~10 个池」= 更细化的同一思路 |
| **Chosen 机制视觉**：动画卡片 + HUD 效果 + 一致色彩，trait tracker 到棋盘单位全链路同色 | Riot ArtBlast（官方美术总结） | 「一致色彩体系」：羁绊色 → 卡牌描边 → 属性页行色 → HUD 徽章同色联动 |

### 1.3 结论（三条硬结论）

1. **池子选择模式**：TFT 英雄传说之力（选池影响抽取）与手游增幅档案（全量可查）证明「自选池 + 全量图鉴」都成立，v1.0.0 三种模式（自选 3~10 池 / 单一总池 / 三大分类池）直接照做。
2. **界面形态**：官方把选择画面做成**全屏大卡牌、稀有度着色、氛围光效**；我们现 UI 是扁长方形小卡片——v1.0.0 方向 = 全屏化 + 大卡牌 + 稀有度光效 + 一键详情。
3. **信息显示**：官方标配「摘要 + 详情覆盖层 + 升级/连锁进度」；我们已有羁绊页签与属性页羁绊框，v1.0.0 将其升级为图鉴化（摘要列表 → 点击详情 → 连锁进度可视化）。

## 3. 界面蓝图（三线全重做）

### 3.1 抽卡主界面（抽取页重做）

```
┌─────────────────────────────────────────────────────────────┐
│  HEXCRAFT WORKSHOP          [自选池] [总池] [分类池]   [图鉴] [配置] │ ← 顶部导航（页签化，大按钮）
│ ┌─────────────────────────────────────────────────────────┐ │
│ │  当前池：自选池（已勾选 7 个）   剩余抽取：N 次   重投 🔄（X 晶币）│ │ ← 池信息条
│ ├──────────────────────┬──────────────────────┬───────────┤ │
│ │  大卡牌 1             │  大卡牌 2             │  大卡牌 3   │ │ ← 三卡横排居中（全屏大卡）
│ │  ┌──────────────┐    │  ┌──────────────┐    │            │ │
│ │  │ 羁绊徽章     │    │  │ 羁绊徽章     │    │            │ │
│ │  │ [稀有度光效] │    │  │ [稀有度光效] │    │            │ │
│ │  │ 海克斯名     │    │  │ 海克斯名     │    │            │ │
│ │  │ 描述（摘要） │    │  │ 描述（摘要） │    │            │ │
│ │  │ 所属羁绊/档位│    │  │ 所属羁绊/档位│    │            │ │
│ │  └──────────────┘    │  └──────────────┘    │            │ │
│ └──────────────────────┴──────────────────────┴───────────┘ │
│   [再抽一次] [重投] [打开图鉴]        （动画：卡牌翻面/稀有度闪光）        │ ← 底部操作区
└─────────────────────────────────────────────────────────────┘
```

**要点**
- 全屏画布（替代当前扁长卡片）；卡牌比例 1.8:1（宽高），三卡横排居中，稀有度色整卡氛围光（银/金/深金/棱彩紫按 v0.9.7 档位色体系延伸）。
- 卡面内容：羁绊徽章（左） + 名称 + 描述摘要 + 所属羁绊/档位徽记 + 已拥有角标。
- 顶部页签化导航：抽取/自选池管理/图鉴/配置，大按钮（≥48px 高，鼠标可达性）。
- 抽卡动画升级：三选一卡牌入场（现有闪光扫线保留）→ 卡牌翻面揭示稀有度 → 选中卡放大落位 + 羁绊进度条更新。

### 3.2 池子选择（自选池模式新增）

```
[自选池] 模式：勾选 3~10 个池
┌──────────────────────────────────────────────────────────────┐
│  池子列表（分类组头：本体 / 联动 / 逆原 / 大乱斗 / 自定义）            │
│  ☑ 原版海克斯（本体）      ☑ 联动·灾变 Cataclysm    ☑ 联动·TACZ    │
│  ☑ 逆原·原点猎场 DLC      ☐ 大乱斗·ARAM 9 套        ☐ 联动·冰与火    │
│  ── 已勾选 5 个（3~10 范围校验，不足/超出按钮置灰）──               │
│  [确定并开始抽取]  [一键全选]  [清空]                              │
└──────────────────────────────────────────────────────────────┘
```

**要点**
- 池 = 现有抽取池体系（本体池/三大分类/联动分系/逆原 DLC/大乱斗），勾选 3~10 个，抽取只从勾选池出。
- 校验：<3 或 >10 时「确定」置灰并提示；与「单一总池」「三大分类池」互斥切换，配置持久化（per-player）。
- 复用现有抽取权重体系（GOLD/weight/稀有度），池选择只改过滤集合，不动权重逻辑。

### 3.3 图鉴（羁绊页签 → 全量图鉴化）

- **列表视图**：现有 47 条羁绊页签升级为「摘要列表」——羁绊名 + 档位色 + 成员数/已集数 + 稀有度徽记；组头分类（原生/新流派/叠层专家/逆原/大乱斗）保留。
- **详情覆盖层**（点击进入）：仿手游增幅资料库——羁绊完整描述、5 档效果逐档展示、成员列表（已拥有高亮）、**连锁进度**（集齐 N 件 → 下一档解锁提示 / 满员棱彩 ×2 提示）、对应机制说明（混键机制如闪电链/飞升/金刚不坏/荆棘装甲）。
- **入口前置**：主界面顶部导航直达图鉴，不必先进属性页（仿手游图鉴入口）。

### 3.4 属性页 / 配置页重做

- **属性页**：保留信息结构（属性/装备/战斗叠层/组合羁绊），版式升级为大尺寸模块化（卡片式分组、宽屏自适应、羁绊行色联动 3.1 稀有度色体系）；羁绊框 hover 行 ↔ 图鉴详情覆盖层互跳。
- **配置页**：沿用 v0.9.7 分类说明 + 统一折叠；新增「界面」分类下 v1.0.0 项：抽卡模式（自选/总池/分类）、卡牌尺寸缩放、动画开关、去重开关。

### 3.5 交互规范（重做）

| 交互 | 规格 |
|---|---|
| hover | 桌面增强：卡片浮起 + 描边发光 + 图鉴行高亮；核心信息不依赖 hover（初始静态可读） |
| 点击 | 卡牌点击 = 选中抽取；图鉴行点击 = 详情覆盖层；覆盖层可 Esc/点击空白关闭 |
| 重投 | 三选一不满意 → 消耗晶币重投（配置可设 0 关闭），被跳过项本会话不再出现（官方随机性优化） |
| 动画 | 全部可跳过/可关闭（性能选项）；入场翻面 + 稀有度闪光 + 选中落位，持续不空转 |
| 去重 | 本会话抽到的海克斯不再重复出现（官方「被跳过不再出现」的延伸）；拥有判定保留 |

### 3.6 显示体系（全量重做）

- **单一色彩体系**：稀有度色（白→银→浅金→深金→棱彩紫）贯通卡牌光效、羁绊行色、HUD 徽章、图鉴徽记——仿 Riot「trait tracker 到棋盘全链路同色」。
- **羁绊徽章**：每条羁绊一枚徽章（名称缩写 + 档位色环），卡牌/图鉴/属性页/HUD 四处复用同一素材。
- **密度自适应**：窗口缩放时卡片/字体按比例缩放（大尺寸窗口优先，小窗自动降密度不溢出）。

## 4. 技术落地要点（MC 1.20.1 Forge 工程约束）

- 界面载体：`Screen` 全屏画布 + `GuiGraphics` 绘制；取消扁长容器，按 `width/height` 动态布局（现状已是动态高度，扩为全屏锚点）。
- 卡牌光效：矩形渐变着色 + 稀有度色描边（延续 v0.9.7 动画降开销思路：单次 fill + 预固化内容，动画期间零翻译零查询）。
- 详情覆盖层：`AbstractContainerScreen` 或全屏叠加层 + 滚动；所有文本进 lang 键（zh/en 同步）。
- 池选择持久化：`PlayerData` 新增字段（每玩家勾选池集合 + 抽卡模式），服务端权威、同步客户端（仿叠层解锁机制做法）。
- 去重：`PlayerData` 本会话已见集合（服务端权威），会话结束清空；与「已拥有」判定分离。
- 配置项：`HexConfig` 新增（抽卡模式默认、重投价格、动画开关、去重开关、卡牌缩放），全部 Cloth 配置页可改。
- 性能：图鉴缓存（现有 cachedBonds 思路扩展）；覆盖层懒渲染；动画统一走 tick 驱动器，可全局关闭。
